════════════════════════════════════════════════════════════════════════
                    STEP-BY-STEP SETUP PROCESS
════════════════════════════════════════════════════════════════════════

PHASE 1: TRANSFER FILES TO MAC STUDIO
──────────────────────────────────────────────────────────────────────

From Laptop (Windows PowerShell):
┌─────────────────────────────────────────────────────────────────────┐
│ scp backend/scripts/create_schema.sql user@macstudio:/tmp/         │
│ scp backend/scripts/setup_rbac.sql user@macstudio:/tmp/            │
└─────────────────────────────────────────────────────────────────────┘


PHASE 2: CREATE DATABASE ON MAC STUDIO
──────────────────────────────────────────────────────────────────────

SSH into Mac Studio:
┌─────────────────────────────────────────────────────────────────────┐
│ ssh user@macstudio                                                  │
│                                                                     │
│ # Create database                                                   │
│ docker exec -i clickhouse-prod clickhouse-client \                 │
│     < /tmp/create_schema.sql                                        │
│                                                                     │
│ # Set up RBAC                                                       │
│ docker exec -i clickhouse-prod clickhouse-client \                 │
│     < /tmp/setup_rbac.sql                                           │
│                                                                     │
│ # Verify                                                            │
│ docker exec -it clickhouse-prod clickhouse-client \                │
│     --database=bizpulse --query="SHOW TABLES"                      │
└─────────────────────────────────────────────────────────────────────┘


PHASE 3: CONFIGURE LAPTOP
──────────────────────────────────────────────────────────────────────

Edit .env on Laptop:
┌─────────────────────────────────────────────────────────────────────┐
│ # File: C:\Users\Sumit Mishra\Documents\Bizpulse\.env              │
│                                                                     │
│ CLICKHOUSE_HOST=192.168.1.100  # ← Your Mac Studio IP              │
│ CLICKHOUSE_PORT=9000                                                │
│ CLICKHOUSE_DB=bizpulse                                              │

│ CLICKHOUSE_PASSWORD=Admin@123!Secure                                │
└─────────────────────────────────────────────────────────────────────┘
